## 5. Angular Coding Standards

Follow these standards:

- Use standalone components.
- Use lazy-loaded routes.
- Use TypeScript strict typing.
- Prefer Angular Signals where appropriate.
- Use `inject()` for dependency injection when consistent with project conventions.
- Use `@if`, `@for`, and modern Angular control flow.
- Use Reactive Forms for complex forms.
- Use `takeUntilDestroyed()` where subscriptions require lifecycle cleanup.
- Keep components focused on UI and presentation.
- Keep reusable business logic inside services.
- Avoid unnecessary subscriptions and duplicated state.
- Use interfaces and models instead of `any`.
- Avoid unnecessary third-party dependencies.
